# Team Capability & Bandwidth Matrix

> Track who can do what, current capacity, and how to work with them - Updated: 2026-04-27

---

## PURPOSE

Centralized view of team capabilities and bandwidth so when you need something done:
- You know who's best positioned to do it
- You know if they're available
- You know how to approach them effectively

---

## LEGEND

**Capacity Levels**:
- 🟢 **Available** (>50% available): Can take on new projects
- 🟡 **Healthy** (20-50% available): Can help with things, but not primary focus
- 🔴 **Overloaded** (<20% available): Only for critical/urgent work

**Domains**:
- **Strategic** (thinking, planning, decision-making)
- **Execution** (doing the work, shipping)
- **Stakeholder** (alignment, communication, buy-in)
- **Technical** (architecture, implementation)
- **Content** (writing, messaging, creative)

## USING THIS FOR PROJECT PLANNING

When assigning work or requesting help:

1. **Check Capacity**: Are they available (🟢/🟡) or overloaded (🔴)?
2. **Check Capability**: Do they have the skill for this task?
3. **Check Timing**: Do I have enough lead time to approach them?
4. **Check Approach**: What's their preferred communication style?
5. **Check Leverage**: What can I offer to make this interesting for them?

**Example Workflow**:
```
Task: Set up Appsflyer tracking for new use case

1. Check capability: Analytics Lead is ⭐⭐⭐⭐ for this ✓
2. Check capacity: 🟡 45% available ✓
3. Check timing: Need 2 weeks → I have 3 weeks ✓
4. Check approach: Async + clear requirements → send Slack doc ✓
5. Execute: Message with specific request, expected timeline, any blockers

Outcome: They respond in 24h with questions, we're done in 1 week
```
