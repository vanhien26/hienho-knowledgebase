## Cách Dùng

### Khi Kick-Off Use Case Mới:

1. **Mở `use-case-document.md`** - đây là master template/skill
2. **Follow 6 pre-flight questions** để gather thông tin cần thiết
3. **Generate BRD theo structure** (Executive Summary → Part 1-4)
4. **Lưu BRD mới vào `Project-Instances/`** folder

### Khi Update Existing Project:

1. **Tìm BRD tương ứng** trong `Project-Instances/`
2. **Update metrics, status, decisions** theo tần suất (weekly/monthly)
3. **Reference back to hienho-master-doc.md** cho consolidated view

## Master Template Content

`use-case-document.md` chứa:
- Trigger words để activate skill (web growth strategy, use case document, etc.)
- Pre-flight checklist (6 câu hỏi bắt buộc)
- Document structure with output examples
- Part 1-4 guidelines (mỗi tối đa 500 từ)
- Mandatory scraping rules (real SERP, real GSC data)
- Appendix templates (keyword universe, URL inventory, etc.)
