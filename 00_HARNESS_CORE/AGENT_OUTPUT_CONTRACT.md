# AGENT OUTPUT CONTRACT

## Với phân tích hoặc review

### Action Title

Một câu kết luận trực diện, nêu chủ đề, hiện trạng và nguyên nhân chính nếu đã đủ bằng chứng.

### What

- Dữ kiện thực tế.
- Kỳ dữ liệu.
- Baseline, target hoặc kỳ so sánh.
- Nguồn SSOT.

### So What

- Tác động tới bài toán kinh doanh, kỹ thuật hoặc trải nghiệm.
- Rủi ro nếu chưa xử lý.
- Điểm chưa đủ bằng chứng.

### Now What

- Hành động cụ thể theo thứ tự logic.
- Capability hoặc file cần dùng.
- Điều kiện cần xác nhận trước khi ghi hoặc đồng bộ.

## Với thao tác đồng bộ hoặc ghi dữ liệu

Phải nêu rõ: phạm vi ghi, file hoặc hệ thống đích, có push bên ngoài hay không, kết quả kiểm chứng và phần chưa hoàn tất.

## Quy tắc bằng chứng

Không gộp fact và inference. Nếu số liệu mâu thuẫn, trình bày mâu thuẫn trước khi đề xuất quyết định.

Evidence của câu trả lời phải tuân theo `EVIDENCE_CONTRACT.md`. Khi có nhiều claim cùng metric và kỳ dữ liệu, Agent phải kiểm tra conflict trước khi kết luận.
