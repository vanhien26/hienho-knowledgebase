# 📖 TỪ ĐIỂN THUẬT NGỮ MOMO × MOSPARK TOÀN DIỆN

> **Cách đọc:** Bảng từ điển này được tổng hợp toàn diện từ mọi khía cạnh của Web Platform: Business, Strategy, SEO/GEO, MoSpark Modules, AI, Metrics, cho đến Organization. Sử dụng cho cả PM, Dev, Data Analyst, và Content/SEO.

## 1 › BUSINESS & STRATEGY TERMS

| Thuật ngữ | Tên đầy đủ / Định nghĩa |
|:---|:---|
| **Content Authority** | Nền tảng có thẩm quyền — vị thế "lựa chọn hàng đầu" khi tìm kiếm giải pháp tài chính số. Vision 2026 cho momo.vn. |
| **Under-served Markets** | Thị trường tiềm năng nhưng chưa được đáp ứng tốt — ưu tiên ngách có volume tìm kiếm lớn nhưng thương hiệu chưa hiển thị tương xứng. |
| **PLG** | **Product-Led Growth** — Web giải JTBD bằng utility/tool tương tác, không chỉ content. User convert vì product solves their job. |
| **PLG Hook** | Tính năng khiến user tự convert mà không cần campaign hay push (e.g., Calculator, Widget tra cứu). |
| **JTBD** | **Jobs-to-Be-Done** — framework xác định "công việc" user thuê sản phẩm để thực hiện. |
| **Product Job Cốt Lõi** | Format phân tích: `[User làm gì] - [User nhận được gì] - [Điều gì xảy ra tiếp theo]`. |
| **S-C-R** | **Situation-Complication-Resolution** — format viết Executive Summary trong các BRD. |
| **S-P-A Framework** | **reSearch → Pilot → Action** — khung 3 giai đoạn triển khai Use Case trên Web Platform. |
| **Value Before Gate** | Nguyên tắc: User PHẢI nhận value trước khi được yêu cầu login hoặc convert (đăng nhập). |
| **Aha! Moment** | Khoảnh khắc user cảm nhận giá trị tức thì (VD: trả kết quả CSGT trong 2s) — trigger chuyển đổi W2A. |
| **Utility-First** | Nguyên tắc: Interactive tools (calculator, simulator, checker) là core value — content là supporting layer. |
| **North Star Metric** | Chỉ số mục tiêu chính — cho MoMo Web là 6M MUA (Monthly Unique Audience). |
| **BNPL** | **Buy Now Pay Later** — Mua trước trả sau (như sản phẩm Ví Trả Sau của MoMo). |
| **Vertical** | Ngành hàng/lĩnh vực kinh doanh chiến lược (VD: Financial Services, Insurance, DVC). |
| **Use Case** | Đơn vị gốc tổ chức mọi content, Ads, analytics — không gắn theo Cell Team hay Division. |
| **Growth Pillar** | 4 trụ cột tăng trưởng: P1-Tài chính & Tín dụng, P2-Bảo hiểm, P3-DVC & Tiện ích, P4-Đời sống & Merchant. |
| **CAC** | **Customer Acquisition Cost** — chi phí để thu hút 1 user mới. |
| **Platform Owner** | Vai trò mới của Web Platform từ 2026: chủ động nghiên cứu cơ hội thay vì hỗ trợ thụ động. |
| **PaaS** | **Platform-as-a-Service** — Mô hình GPD cung cấp tư vấn + quy trình + nền tảng cho Cell Teams. |
| **Bữa tối gia đình Test**| Tiêu chuẩn sản phẩm: Phải tạo Aha! Moment đủ mạnh để user tự kể cho người khác trong bữa tối gia đình. |

## 2 › SEO & GEO TERMS

| Thuật ngữ | Tên đầy đủ / Định nghĩa |
|:---|:---|
| **SEO** | **Search Engine Optimization** — tối ưu hóa để trang hiển thị tốt trên Google Search. |
| **GEO** | **Generative Engine Optimization** — tối ưu hóa citation/trích dẫn trên AI Search (ChatGPT, Perplexity, Gemini). |
| **AEO** | **Answer Engine Optimization** — thuật ngữ tương đương GEO, tối ưu cho AI engines trả lời. |
| **AIO** | **AI Overview** — kết quả AI tổng hợp xuất hiện trên đầu trang SERP của Google. |
| **SoV** | **Share of Voice** — % hiển thị MoMo vs đối thủ trên SERP/AI. `SoV = Impression (GSC) / Total Volume Search`. |
| **YMYL** | **Your Money Your Life** — nội dung tài chính/sức khỏe/pháp lý bị Google đánh giá khắt khe hơn; cần E-E-A-T cứng. |
| **E-E-A-T** | **Experience, Expertise, Authoritativeness, Trustworthiness** — bộ tiêu chí đánh giá chất lượng nội dung của Google. |
| **pSEO** | **Programmatic SEO** — sinh trang quy mô lớn từ template + data (VD: tạo 63 trang tỉnh thành phạt nguội). |
| **SERP** | **Search Engine Results Page** — trang kết quả tìm kiếm của Google. |
| **Topical Authority** | Mức độ Google/AI đánh giá website là nguồn đáng tin cậy và chuyên sâu về một chủ đề cụ thể. |
| **Fact Density** | Mật độ số liệu/thống kê thực tế trong nội dung. AI engine ưu tiên cite nội dung có fact density cao. |
| **Content Decay** | Hiện tượng bài viết giảm traffic/ranking theo thời gian, đòi hỏi phải Content Refresh/Rewrite. |
| **Keyword Cannibalization**| Tự cạnh tranh thứ hạng nội bộ do có quá nhiều trang trên cùng 1 site target cùng 1 keyword. |
| **Pillar Page / Hub** | Trang trụ cột chất lượng cao, tập trung tổng hợp từ nhiều bài nhỏ lẻ. |
| **Hub & Spoke** | Mô hình cấu trúc nội dung: 1 Hub Page (trang tổng quan) + nhiều Spoke Pages (trang chuyên sâu hỗ trợ). |
| **Keyword Clustering** | Phương pháp gom nhóm từ khóa theo chủ đề (Cluster) để bao phủ trọn vẹn nhu cầu tìm kiếm. |
| **Answer-First** | Cấu trúc đoạn đầu trả lời trực diện câu hỏi trong 40-60 từ — bắt buộc cho chiến lược GEO. |
| **Canonical Tag** | Thẻ HTML khai báo URL "chính thống" (bản gốc) để Google không nhầm lẫn khi có URL trùng lặp nội dung. |
| **Robots Meta / Noindex** | Chỉ thị khai báo cho Google biết có được phép crawl và index trang vào kết quả tìm kiếm hay không. |
| **Orphan Page** | Trang mồ côi — không được bất kỳ trang nào khác link tới, khiến bot khó tìm. |
| **Internal Link** | Liên kết nội bộ — link từ một trang momo.vn sang một trang khác trên momo.vn. |
| **Crawl Budget** | Ngân sách cào dữ liệu — số trang giới hạn mà bot Google crawl trong một khoảng thời gian nhất định. |
| **Schema / JSON-LD** | Dữ liệu có cấu trúc chuẩn Schema.org giúp máy (AI/Google) hiểu rõ thực thể trên trang. |
| **Disclaimer** | Tuyên bố miễn trừ trách nhiệm — bắt buộc phải có trên nội dung tài chính YMYL. |
| **Named Author Policy** | Chính sách bắt buộc: Mọi bài YMYL phải hiển thị danh tính chuyên gia/người duyệt thực tế. |
| **Information Gain** | Yếu tố độc quyền (screenshots thực, data nội bộ) giúp AI engines ưu tiên trích dẫn. |
| **Co-occurrence** | Việc xuất hiện đồng thời các entity liên quan trong ngành để giúp AI hiểu rõ context. |
| **PAA** | **People Also Ask** — khung câu hỏi liên quan mà Google gợi ý trên SERP. |
| **AI Citation Rate** | % tỷ lệ các query mà MoMo xuất hiện trong câu trả lời của AI engines (Mục tiêu: 30%+). |
| **Near Miss Keyword** | Từ khóa đang ở rank 4-15 có volume lớn — cơ hội tăng traffic mạnh nếu tối ưu nhẹ. |

## 3 › CONTENT FUNNEL TERMS

| Thuật ngữ | Định nghĩa |
|:---|:---|
| **TOFU** | **Top of Funnel** — Nội dung Informational (tìm hiểu, giải đáp kiến thức), user mới bắt đầu hành trình. |
| **MOFU** | **Middle of Funnel** — Nội dung Commercial (so sánh, đánh giá, review), user đang cân nhắc. |
| **BOFU** | **Bottom of Funnel** — Nội dung Transactional (hướng dẫn mở thẻ, bảng giá, đăng ký), user sẵn sàng hành động. |
| **Search Intent** | Ý định tìm kiếm: Informational (Know), Commercial (Compare), Transactional (Do/Buy), Navigational (Go). |

## 4 › ANALYTICS & METRICS

| Thuật ngữ | Tên đầy đủ / Định nghĩa |
|:---|:---|
| **MUA** | **Monthly Unique Audience** — chỉ số chính yếu 2026 (đo qua BigQuery thay vì GA4), mục tiêu 6M. |
| **MUV** | **Monthly Unique Visitors** — tương đương MUA. |
| **MAU** | **Monthly Active User** — người dùng có hành vi phát sinh giao dịch (Cashin event) trong tháng trên App. |
| **MEU** | **Monthly Engagement User** — đo lường tương tác với tính năng tiện ích (tra cứu, xem info) thay vì giao dịch. |
| **DLU / MLU** | **Daily/Monthly Line User** — mức độ user tương tác và sử dụng các công cụ PLG hàng ngày/tháng. |
| **New User** | Người dùng Install và Register thành công MoMo App. |
| **W2A** | **Web-to-App conversion** — tỷ lệ chuyển đổi user từ Web sang App qua deep link; target ≥ 12.5%. |
| **CR** | **Conversion Rate** — tỷ lệ chuyển đổi tổng quát. |
| **CTR** | **Click-Through Rate** — tỷ lệ click trên số lần hiển thị. |
| **Organic Traffic** | Sessions từ kênh tự nhiên (Google, Bing, AI Search) — không tính ads, direct, social, referral. |
| **Zero-Traffic URL** | Các trang "chết" — có dưới 100 organic sessions trong 90 ngày, cần được xử lý theo policy. |
| **OKR / KR / KPI** | **Objectives and Key Results** / **Key Result** / **Key Performance Indicator** — các chỉ số đo lường hiệu suất. |
| **SEO-ICE Score** | Điểm ưu tiên SEO: `(Volume × (Target SoV - MoMo SoV) × Expected W2A CR) / Complexity`. |
| **NTS** | **New to Services** — % tỷ lệ người dùng mới (chưa từng dùng) tiếp cận và xài dịch vụ. |
| **AOV** | **Average Order Value** — giá trị đơn hàng trung bình. |

## 5 › TECHNICAL & PLATFORM (MoSpark Ecosystem)

| Thuật ngữ | Tên đầy đủ / Định nghĩa |
|:---|:---|
| **MoSpark** | **AI-Powered Growth Platform / Growth OS** của momo.vn — không phải CMS thông thường mà là hệ điều hành tăng trưởng. |
| **Mobase** | Design System nội bộ (`@momo-webplatform/mobase`) — hệ thống component chuẩn hóa UI/UX Web. |
| **Puck Editor** | Trình biên tập trực quan dạng kéo thả (drag & drop) cho Landing Page và Microsite. |
| **Tiptap Editor** | Bộ soạn thảo WYSIWYG tích hợp cho Blog Editor. |
| **Onelink** | Appsflyer deep-link service — "xương sống" cho W2A. Cấu trúc: `momoapp.onelink.vn/[id]?pid=&c=&af_dp=`. |
| **Appsflyer** | Nền tảng phân tích attribution chuyên dụng đo lường W2A conversion thực tế. |
| **Umami** | Web analytics tracking (self-hosted) dùng để đo PageView, Clicks trực tiếp trên UI MoSpark. |
| **BigQuery** | Data warehouse làm **Single Source of Truth** cho MUA/traffic, loại bỏ sai số của GA4. |
| **GA4 / GTM** | Google Analytics 4 & Google Tag Manager (Container ID: GTM-P9JDDJZ). |
| **GSC** | Google Search Console — check lỗi indexing, tracking organic impressions, clicks. |
| **CWV** | **Core Web Vitals** — 3 chỉ số hiệu năng tốc độ web cốt lõi (LCP, INP, CLS). |
| **LCP / INP / CLS** | **LCP** (thời gian tải khối lớn nhất ≤2.5s), **INP** (độ trễ tương tác ≤200ms), **CLS** (giật layout ≤0.1). |
| **FCP / TTFB** | **FCP** (nội dung đầu tiên ≤1.8s), **TTFB** (phản hồi server ≤800ms). |
| **DOM** | Cấu trúc object HTML của trang web. |
| **Signed URL** | URL preview nháp có gắn token bảo mật. |
| **Lab Data vs Field Data** | **Lab Data:** Số đo trong môi trường test kín (Lighthouse). **Field Data:** Số đo thực tế từ Chrome UX Report (CRuX). |
| **llms.txt / robots.txt**| File chỉ dẫn cho AI crawlers (`/llms.txt`) và search engine bot (`/robots.txt`). |
| **Supabase / YARP** | Supabase (DB Platform) và YARP (API Gateway) dùng cho backend MoSpark. |
| **SSO / RBAC** | Single Sign-On / Role-Based Access Control — đăng nhập tập trung và phân quyền HRM. |
| **wui** | **Web User Identifier** — ID ẩn danh tracking user web để đối soát khi truyền vào Onelink. |
| **Typebot** | Công cụ build flow kịch bản cho chatbot (dùng tích hợp Help Center). |

## 7 › MOSPARK SPECIFIC CONCEPTS

| Thuật ngữ | Định nghĩa |
|:---|:---|
| **Score Panel / Hard Block** | Bảng điểm SEO/GEO. **Hard Block** là tiêu chí bắt buộc (nếu fail = chặn nút Publish ngay). |
| **Publish Gate** | Cổng xét duyệt nội dung tự động: `<60` = Block, `60-79` = Warning, `≥80` = Pass. |
| **7-Step Workflow** | Quy trình sinh bài: 1.Market → 2.Context → 3.Keyword → 4.AI Outline → 5.Edit → 6.AI Detail → 7.Score/Publish. |
| **Business Context** | 12 trường metadata định nghĩa ngữ cảnh kinh doanh (Source of Truth) cho AI bám sát khi sinh nội dung. |
| **Keyword Master Registry** | Kho lưu trữ "sổ cái" toàn bộ keyword. **Quy tắc vàng: 1 Keyword = 1 URL Master**. Không có ngoại lệ. |
| **Bottom-Up / Top-Down Sync**| Tính năng tự động đồng bộ 2 chiều giữa CMS truyền thống và GenAI Engine khi tạo mới Keyword. |
| **Content Writer Agent** | Mỗi dự án có một AI Agent chuyên biệt được custom prompt riêng. |
| **Placement Registry** | Kho lưu slot vị trí quảng cáo (Use Case nội bộ + GPD share chung). |
| **Native Widget (Shortcode)**| Mã nhúng ad format vào bài: `[widget:phat-nguoi]`. (Tạo W2A CR cao nhất). |
| **Integrity Guard** | Ràng buộc CMS: Tạo PLG Project phải liên kết 1 Microsite + 1 SEO Inventory. |
| **GEO/Data Moat** | Hào nước bảo vệ dữ liệu tương tác từ PLG Tool mà LLM bên thứ 3 không thể tự cào/copy được. |
| **Content Remix Engine** | Công cụ tái chế một nội dung ra nhiều định dạng khác (âm thanh, video, tóm tắt). |

## 8 › AI & GENAI TERMS

| Thuật ngữ | Định nghĩa |
|:---|:---|
| **GenAI / LLM** | Generative AI sử dụng các mô hình ngôn ngữ lớn (Claude, Gemini, GPT) để tự động hóa viết lách. |
| **RAG** | **Retrieval-Augmented Generation** — truy xuất nội dung cào từ Vector DB để AI bot trả lời chính xác thực tế. |
| **Vectorization** | Chuyển đổi văn bản thành vector embeddings phục vụ semantic search và RAG. |
| **Semantic Linking** | Tự động suggest Internal Link nhờ đo lường khoảng cách vector embeddings. |
| **Grounding Search** | Cơ chế bắt buộc AI kiểm tra thông tin thực tế/real-time để chống ảo giác (hallucination). |
| **Human-in-the-loop** | Yêu cầu bắt buộc phải có người/chuyên gia kiểm duyệt bài YMYL sau khi AI sinh ra. |
| **Safe-Harbor Gate** | Phân loại rủi ro bài viết AI để đưa qua các cổng kiểm duyệt (Tiered Compliance). |
| **GenAI Chargeback** | Hệ thống đo lường số Token API AI sử dụng để tính chi phí và trừ vào budget Cell Team. |
| **Agentic** | Hệ sinh thái AI vận hành độc lập tự chủ (Tầm nhìn platform 2027+). |

## 11 › TRACKING & CONVERSION PIPELINE

| Thuật ngữ | Định nghĩa |
|:---|:---|
| **Funnel Tracking** | Hành trình chuẩn: `Traffic → Engagement → CTA Click → App Open → Completion (Txn)`. |
| **W2A Funnel Stitching** | Nối data end-to-end từ lúc user ở Web đến khi Login thành công vào MAU trên App qua BigQuery. |
| **Contextual/Smart CTA** | Nút Call-to-action thay đổi linh hoạt theo ngữ cảnh hoặc số liệu user vừa nhập vào widget. |
| **Deep Link** | Link nhảy trực tiếp tới màn hình App (VD: `momo://app/insurance/...`). |
| **UTM / pid** | Các tham số url để truy vết nguồn gốc click. `pid` là parameter dùng trong Onelink (`seo`, `inbound`). |
| **Zero-Party Data Passing**| Cơ chế truyền trực tiếp số liệu user tự nhập (ví dụ: lương 10 triệu) vào app MoMo mà user không cần nhập lại. |
| **Revenue Attribution** | Tính toán % ROI từ Web-to-App cho từng Use Case đóng góp vào Business tổng. |
| **On-site Retargeting** | Phân phối ads cá nhân hóa dựa trên hành vi ẩn danh tracking ở Local Storage mà không cần user Login web. |

## 13 › WORKFLOW & ADS FORMATS

### Quy trình (Workflow)

| Thuật ngữ | Định nghĩa |
|:---|:---|
| **Govern - Build - Execute**| Tam giác vận hành: GPD (Govern/Policy) → Platform/Dev (Build) → Cell Team/Inbound (Execute). |
| **9-Step Workflow** | Quy trình ra mắt Web: Research → Target → Brief → Feasibility Sync → Sprint → SEO Review → Staging → Roll Out → Post-Launch. |
| **Stage Gate** | Các mốc đánh giá Stop/Go giữa các giai đoạn S-P-A. |
| **1 Keyword = 1 URL** | Hệ thống MoSpark sẽ block không cho phép tạo 2 bài viết nếu chung 1 Primary Keyword. |

### Ads Formats (W2A)

| Format | Đặc điểm |
|:---|:---|
| **Float** | Banner nổi góc dưới, trượt theo màn hình. |
| **Balloon** | Bóng bay nổi bật góc dưới (độ phiền phức/interrupt thấp). |
| **Popup** | Bật chình ình toàn màn hình (Max 1 lần/session để tránh spam). |
| **Inline / Sticky Bar** | Banner chèn giữa đoạn văn / Thanh gắn chặt mép trên/dưới màn hình. |
| **Shortcode Widget** | Nhúng thẳng module chức năng (Ví dụ: Bảng tính lãi) trực tiếp vào giữa bài viết. |
