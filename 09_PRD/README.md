# 08_PRD - Product Requirements Documents

> Version: 1.0 | Created: 2026-06-06 | Maintained by: Văn Hiến

## Mục đích

Folder này chứa PRD (Product Requirements Document) cho từng Use Case của MoMo Web Channel.

**Phân biệt BRD vs PRD trong hệ thống này:**

| | BRD (05_USE_CASE_MOMO) | PRD (08_PRD) |
|---|---|---|
| Audience | Stakeholder, Leadership | Engineering, Design |
| Focus | Why + What (business case) | How (product specs) |
| Input | Market data, Keyword research | BRD + UX decisions |
| Output | Alignment, Go/No-Go | Build-ready specs |

## Naming Convention

```
[use-case-slug]-prd.md
```

Ví dụ: `phat-nguoi-prd.md`, `gia-vang-prd.md`

## Status Tags

- `[DRAFT]` - Chưa review
- `[IN REVIEW]` - Đang review với stakeholder
- `[APPROVED]` - Đã approve, sẵn sàng build
- `[IN BUILD]` - Đang trong sprint
- `[LIVE]` - Đã deploy
